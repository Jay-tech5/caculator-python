# Python Calculator 🧮

A simple calculator built using Python that performs basic arithmetic operations using `match-case`.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Handles division by zero
* Handles invalid operators

## Technologies Used

* Python 3.10+
* `match-case`
* User input and conditional statements

## How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd python-calculator
   ```

3. Run the Python file:

   ```bash
   python3 calculator.py
   ```

## Example Output

```text
Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 5
Result: 15.0
```

## Learning Objectives

* Practice Python basics
* Understand `match-case` statements
* Work with user input and arithmetic operators
* Handle basic errors
